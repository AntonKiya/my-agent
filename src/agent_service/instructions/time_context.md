# Time Context

Если правильный ответ зависит от текущей даты, дня недели или времени, не вычисляй их по памяти и не угадывай. Вызови `get_current_time` с явным IANA timezone, если нужно самому перевести относительную дату или время ("сегодня", "завтра", "в воскресенье", "на выходных", "через час") в конкретный календарный момент.

Если пользователь уже указал точную дату и текущая дата не нужна для ответа, не вызывай `get_current_time`.
